# OPC-OS 控制台 · 文案与调性规范（Console Voice & Tone）

> 版本 v1.0（2026-09-16）。产品主轴：**创意变现**（创意 → 作品 → 收入）。
> 本规范约束控制台全部界面文案；新增面板/文案 PR 先对照本表自查。

## 1. 调性六原则

1. **主语是"你的创意"**：第二人称、鼓励性。说"你的第 3 篇作品发布了"，不说"content_publish 事件已触发"。
2. **每个面板回答一个变现问题**：面板副标题必须说明"这一段漏斗怎么帮你赚钱"，而非描述功能。
3. **数字先行**：能亮收入/数量的位置先亮数字（大字号），解释文字退居副标。金额一律自动分→元，收入用正向色。
4. **动词即按钮**：按钮说人话、说结果——"记下这个创意""马上出作品""上架收钱"，禁用"提交/确认/确定"。
5. **空态即引导**：空态文案 = 现状一句 + 行动召唤一句，永远给用户下一步。
6. **术语收进副标**：RaaS、乐观锁、waterfall 等技术词不上主文案；需要时以小字/tooltip 出现。

## 5. 结果与错误文案

| 场景 | 文案模板 |
|---|---|
| 内容发布成功 | `第 {n} 份作品发布成功 · 合规分 {score} · 用时 {duration}`（附链接） |
| 审核被拒（2 轮后） | `这篇没过审：{violation 摘要}。教训已存入资产库，改写后再试` |
| 记创意成功 | `已记下。跑一次「出作品」，它会变成你的选题` |
| 上架成功 | `「{name}」已上架，定价 ¥{price}——去货架看看` |
| 支付失败 | `这笔支付没成（{reason}），订单还挂着，可重试支付或取消` |
| 支付成功 | `收到 ¥{amount}！创作者分得 ¥{creator}，平台 ¥{platform}` |
| 计费结算 | `这单自主解决，计费 ¥{amount}；若是转人工则不收费` |
| 预算告警 | `团队 token 已用 {ratio}——快到预算线了` |
| 预算拦截 | `预算已耗尽，本轮不再执行。可调大 tokenBudget 后继续` |
| 未知错误 | `出了点小状况（{code}）。创意和收入数据不受影响，重试即可` |

## 6. 禁用清单

- 禁用：`提交`、`确认`、`操作成功`、`数据加载完毕`、`参数错误`、裸错误码当正文（code 放小字）
- 禁用把技术组件名当面向用户名词：waterfall、乐观锁、firehose、LRU（写行为不写机制）
- 金额必须分→元换算后呈现，禁止裸"990 分"
- 中英文间加空格；不使用感叹号超过每屏 1 个

## 7. 落地方式

按本表逐面板替换 app.js/index.html 现有文案（品牌区、面板标题/副标、按钮、空态、toast 模板）；漏斗四段命名同步总览漏斗视图。文案改动属静态资源，热生效无需重启 `dsh web`。
