# OPC-OS（CreativeOS）创意者用户指南

**让每个创意都有收入。** OPC-OS 是一套跑在浏览器里的创意变现操作系统：创意从这里进入，经 AI 团队变成作品，在市场与客户那里变成收入——**创意 → 作品 → 收入**，一条漏斗走到底。

本指南面向使用控制台的创意者（不需要任何编程基础）。开发与部署相关的技术文档见仓库 `readme.md` 与 `docs/` 目录。

## 1. 快速上手：从记创意到收钱

第一次使用，跟着这七步走一遍，你就完成了创意变现的完整闭环。

### 1.1 注册并登录

打开控制台（本地运行默认 `http://127.0.0.1:3000`，或部署者给你的网址），会看到 CreativeOS 全屏登录卡。

1. 点「还没有账号？注册一个 →」切换到注册。
2. 填**用户名**（2–32 位字母 / 数字 / 下划线）、**密码**（至少 6 位）、**昵称**（可选，会显示在界面右上角）。
3. 点「注册并进入」——注册即登录，直接进入控制台。

之后每次打开控制台都已自动登录（会话最长 7 天不活跃才过期）。连续输错密码会短暂锁定，按提示等几十秒再试即可。

### 1.2 记下第一个创意

在左侧导航点**总览**，页面正中就是四段创意变现漏斗：

```
① 记下的创意 → ② 发出的作品 → ③ 在售的技能 → ④ 到手的收入
```

在第①段输入框写下创意（比如「宠物经济测评」），点**「记下这个创意」**。系统会自动：

- 生成**三域草案**——问题域 / 解决域 / 时空域，帮你把想法想清楚；
- 初始化这条创意**专属的记忆体**（它自己的记忆，不和别人混）；
- 初始化它的**子操作系统**与独立工作区。

> 提示：如果你加入了团队，录入框旁可以选「个人创意」或某个团队——团队创意队友也能看到、能接着推进。

### 1.3 三域迭代：把想法想清楚

到**我的创意**，点「打开详情」，第一个页签「三域与版本」就是创意的思考区：

- 每个域上方都有**引导问题**（比如问题域：「谁在为什么场景付费？」），照着答就行；
- 在「概述」写一段总结，在「要点」一行一条列要点，点**「保存这个域」**；
- 每次保存都会**自动存成一个新版本**。改砸了随时在下方「三域版本链」点**「回滚到此版」**——当前内容会先存为新版本，历史永不丢，回滚了还能再撤销。

### 1.4 阶段推进：描述 → 产品 → 运营 → 资产

创意详情顶部有四个阶段按钮：**创意描述 → 创意产品 → 产品运营 → 产品资产**。生命周期只允许线性向前推进，当前阶段的下一个按钮可点击：

1. 点下一个阶段按钮；
2. 填一句**推进依据**（如「MVP 验证过线 / 内测数据达标」）；
3. 点**「确认推进」**——依据会写入这条创意的决策记忆，有据可查。

到了「创意产品」阶段，去「MVP 验证」页签：点**「生成 MVP 方案」**拿到功能清单、技术栈建议和开发计划；每做一次内测或看一次数据，就**「记一条验证」**（用户反馈或数据指标 + 0–5 评分）。验证攒够了，系统会给出 **Go / No-Go** 建议——Go 就放心往下推进，No-Go 会告诉你还缺什么。

### 1.5 出作品：内容流水线

到**内容引擎**（副标题「出作品」）：

1. 「用哪个创意的人设」选你的创意（也可以不选，走全局人设）；
2. 点**「马上出作品」**。

流水线会自动完成 选题 → 撰写 → 审核 → 发布，结果卡里能看到：标题、人设分、差异化角度、合规审核结果（含 E-E-A-T 四维检查）、发布链接，以及**五平台分发**（公众号 / 小红书 / 抖音 / Twitter / B站）的逐平台回执。

作品发布成功且质量达标（E-E-A-T 四维全过），这篇的写法会自动沉淀为**爆款模板**存进这条创意的记忆，下次写得更像它。

### 1.6 发市场

在**我的创意**详情里切到「市场与协同」页签，点**「发布到市场」**。发布后：

- 全网创意者都能搜到、关注这条创意；
- 系统自动发现与你**互补或相似**的关联创意；
- 别人的关注与协同贡献都会记录在案并发放积分。

### 1.7 收入：订单分成 / 订阅 / RaaS

收入的通道有三条，全部在经营面板组：

- **Skill 上架收钱**：内容流水线跑几次后，重复的工作流会被本能系统自动蒸馏成 Skill 草案；到 **Skill 市场**点**「上架收钱」**（默认定价 ¥9.90）。买家下单支付后，**创作者拿 85%**。
- **订单分成**：买家在**订单交易**里下单付款，分成明细当场可见，自动入账你在**创作者中心**的余额。
- **RaaS 数字员工计费**：数字员工每**自主解决**一单任务计费 ¥2.50，转人工则不收费，在 **RaaS 计费**结算。

到这一步，你就走完了「记创意 → 出作品 → 上架 → 收钱」的完整闭环。回总览看看——漏斗四段的数字都会动起来。

## 2. 工作台面板

### 2.1 总览——今天，你的创意走到哪一步了

**是什么**：控制台首页，一屏回答一个变现问题：你的创意今天走到漏斗的哪一段了。

**怎么用**：

- **漏斗四段**：①记下的创意 → ②发出的作品 → ③在售的技能 → ④到手的收入（订单净额 + RaaS）。第①段可直接写创意，第②段可一键「运行内容流水线」；
- **最近创意**：最新 5 条，点击直达；
- **系统状态**：一行字说明多少个组件在线（异常会点名）；
- **最近埋点事件**：折叠区，技术向的系统时间线，不用管也不影响使用。

**常见问题**：

- *漏斗数字准吗？* 数字按你的登录身份统计——只算你的、你的团队的，以及早期的无主存量数据。
- *记错了创意想删？* 暂不支持删除，可用「我的创意」里的**归档**隐藏它（见 [FAQ](#9-常见问题-faq)）。

### 2.2 我的创意——每个创意都是独立的生命体

**是什么**：你的创意库。每条创意有自己的三域描述、自己的记忆体、自己的工作区与资产账本——互不干扰。

**怎么用**：

- 列表卡片显示创意名、当前阶段、问题域摘要；「打开详情」进入，**「归档」**隐藏（可恢复）；
- 详情按旅程分成 6 个页签，切换不用重新加载：

| 页签 | 里面有什么 |
| --- | --- |
| 三域与版本 | 问题域 / 解决域 / 时空域编辑（带引导问题）+ 版本链与回滚 |
| MVP 验证 | 生成 MVP 方案、启动 Agent 开发、记验证、Go/No-Go、工作区文件 |
| 运营（GEO·人设） | 每创意独立人设编辑 + GEO 监测（四平台指标与趋势） |
| 资产·Token | 财务 / Skill / 用户 / 运营数据四张账本卡 + Meme Token 积分发放 |
| 市场与协同 | 发布到市场、关联创意、协同贡献记录 |
| 记忆体·工作区 | 这条创意的记忆检索 / 写入 / 挂载 + MVP 开发文件 |

- **记忆体**：7 条记忆流（描述 / 决策 / 调研 / 模型笔记 / 品牌事实 / 用户 / 运营数据），可检索（3 个字以上任意词）、可手写沉淀；写入时可选「用户钦定」（你说的话，最权威）或「模型总结」（AI 归纳的）；
- **挂载记忆体**：只有「已挂载」的记忆体才参与跨创意检索。列表上方一行字会提示当前挂载了哪些；
- 把详情页网址直接发给队友（`#/ideas?id=创意ID`），对方打开就是这条创意。

**常见问题**：

- *推进按钮点不动？* 生命周期只能线性向前，只有「当前阶段的下一个」可点；推进需要填依据。
- *回滚会丢数据吗？* 不会。回滚前系统自动把当前三域存为新版本，随时可以再滚回来。

### 2.3 内容引擎——出作品

**是什么**：把创意变成能发布、能涨粉的作品的生产线。

**怎么用**：

1. 「用哪个创意的人设」下拉选创意——每条创意的人设相互隔离，出稿风格跟着各自的人设走；
2. 点**「马上出作品」**（配置了 DeepSeek API Key 时走 LLM 撰写，可能需数秒；没配置走内置模板策略，照样能出稿）；
3. 结果卡显示：标题、人设分（/5）、差异化角度、合规审核（违规项分级 / 合规分 /100 / E-E-A-T 四维）、发布链接、五平台分发回执；
4. 下方「最近发布事件」每 10 秒自动刷新，「运行统计」告诉你当前是 LLM 撰写还是模板策略、热点选题是接入网络还是常青库兜底。

**常见问题**：

- *审核没过？* 违规项会分级列出，按提示改；教训会自动存进资产库。
- *发布到真实平台了吗？* 平台分发返回适配与回执链接；未配置对应平台凭据时为演示口径。

### 2.4 创意资产——越用越准的资产库

**是什么**：你的记忆资产库——人设、爆款模式、踩过的坑，全程自动沉淀，反哺下一轮创意。

**怎么用**：

- 默认视图「**创意三件套**」= 创意选题（topic）+ 爆款模式（fact）+ 教训（lesson），是直接反哺选题的黄金组合；也可以切到七类单类视图：人设（soul）/ 受众（user）/ 矩阵（project）/ 爆款模式（fact）/ 教训（lesson）/ 创意选题（topic）/ 红线（rules）；
- 顶部输入关键词全文检索，各页签带条目计数徽标（单类最多显示 50 条，「50+」表示不少于 50）；
- 下方「写入资产」可以手动存一条：选类别、作用域、置信度，写内容点**「存为资产」**。**创意选题（topic）类资产会被内容流水线的选题策略直连为候选**——你随手记的灵感，下次「出作品」就可能被写成稿。

**常见问题**：

- *资产是谁写进去的？* 三类来源：创意与发布过程自动沉淀、教训自动入库、你手动写入。你的资产只有你能看到（按账号隔离）。

## 3. 增长面板

### 3.1 创意市场

**是什么**：看别人的创意走到哪了，关注它、和它协同。

**怎么用**：

- **搜创意**：输入关键词（问题域 / 解决域 / 时空域的词都行），配合阶段筛选，点「搜创意」；
- **关注**：点列表里的「+ 关注」，这条创意**阶段一变就会通知你**；「我的关注」可随时取消；
- **我的通知**：关注的创意有阶段变更时在这里出现；
- **三张榜单**：资产榜（谁收入高）、社区榜（谁关注多）、GEO 榜（谁在 AI 平台上更显眼）。

**常见问题**：

- *发布后想撤下来？* 在「我的创意」里归档该创意，市场同步下架。
- *为什么关注/协同要登录？* 市场互动强制实名——关注与协同都记录真实账号，贡献才发得对积分。

### 3.2 Skill 市场——上货架

**是什么**：你的重复劳动，别人愿意付钱。本能系统会把重复执行的工作流自动蒸馏成 Skill 草案，你审核后上架。

**怎么用**：

- **从草案上架**：顶部「Skill 草案（本能提炼）」区，点**「上架收钱」**——系统重新签名打包后写入市场索引，默认定价 ¥9.90（community 分类）；
- **逛货架**：按名称、类别、生命周期阶段、兼容版本搜索；每行显示定价（免费 / 一次性 / 订阅）、下载量、评分；
- **安装**：选「安装到：个人（全局）或某个创意」，点「安装」——装进创意就是装进它的子操作系统；
- **订阅制 Skill**：先点「订阅」（下单支付后权益生效），再安装。

**常见问题**：

- *货架是空的？* 正常——先去跑几次内容流水线，本能系统会替你蒸馏出第一个技能。
- *安装提示需要有效订阅？* 这是订阅制 Skill 的权益校验：回「订单交易」订阅该 Skill 后再装。

## 4. 协作面板

### 4.1 协作团队

**是什么**：多用户协作的组织层——一个队伍共享一组创意：成员都能看、都能接着推进。

**怎么用**（建队 / 邀请详见[第 7 节](#7-团队协作指南)）：

- 「创建队伍」填队名点**「建队」**；
- 每支队伍卡片下按**用户名**邀请成员；队长可以点成员徽标上的 × 移出队伍；
- 你创建的队伍标「我创建」，加入的标「成员」。

**常见问题**：

- *邀请没反应？* 确认对方已经注册，且用户名拼写一致（含大小写与下划线）。

### 4.2 AI 组队

**是什么**：说一句目标，AI 团队替你把活干了。

**怎么用**：

1. 在「创业目标」里写一句话（如「帮我做一个跨境电商独立站」），点**「组队开工」**；
2. 系统解析目标后给出角色卡片（角色名 + 职责）；
3. 目标解析失败时会降级：页面出现行业模板按钮（跨境电商创业团队、独立开发者团队等），点一个模板名会填回输入框，再试一次。

**常见问题**：

- *和「协作团队」什么区别？* 「协作团队」管**真人**队友的组织与权限；「AI 组队」是让 **AI 角色**按你的目标开工。

### 4.3 任务板

**是什么**：共享任务板——团队在为你的创意干活，谁认领了什么一目了然。

**怎么用**：

1. 顶部填任务标题（如「整理竞品清单」）和你的成员 ID，点**「添加任务」**；
2. 任务四种状态：待认领（pending）→ 进行中（claimed）→ 已完成（done），异常时标**阻塞**（blocked）并写原因；
3. 每行操作按钮随状态变化：待认领可「认领」，进行中可「完成」（填交付结果）或「阻塞」；
4. 顶部统计卡实时显示各状态数量，页面每 10 秒自动刷新。

**常见问题**：

- *提示「这条任务刚被别人更新了（vN）」？* 两个人同时操作同一条任务，系统按版本号保护——已自动为你刷新最新状态，重试即可，不会互相覆盖。

### 4.4 黑板

**是什么**：团队的公共记忆墙，谁写了什么都能看见。AI 协作时各角色通过黑板交换发现与结论。

**怎么用**：

- 两个作用域页签：**Global·全局**（只有 orchestrator 角色可写）与 **Workflow·任务**（参与任务的 Agent 可读写）；
- 写入：填 Key、Value（JSON 格式）、写入者与角色、期望版本号，点**「写到黑板」**；
- 冲突时（条目刚被别人更新）会提示当前版本号并自动回填，改一下再写即可。

**常见问题**：

- *Value 必须是 JSON？* 是。简单内容可以写 `{"summary": "一句话"}` 这样的最小结构。

## 5. 经营面板

### 5.1 订单交易

**是什么**：买 Skill、看订单、管订阅的地方。每一笔确认的订单，创作者拿 85%。

**怎么用**：

- **下单**：选 Skill → 确认买家 ID → 金额（单位是**分**，¥9.90 填 990）→ 点「创建订单」；
- **支付**：订单列表里对未支付订单点「支付」，成功后当场显示分成明细（创作者 85% / 平台 15%）；
- **我的订阅**：填买家 ID 点「刷新订阅」，查看订阅权益窗口、剩余天数、自动续订开关与续订按钮（详见[第 8 节](#8-订阅与自动续订)）；
- **订单列表**：按买家 ID 过滤查询（后端必填 buyerId）。

**常见问题**：

- *金额填错单位？* 金额一律按**分**计：¥9.90 = 990，¥99 = 9900。
- *看别人的订单？* 不行——订单、订阅、账单都只认登录者本人，防止越权与冒名下单。

### 5.2 创作者中心

**是什么**：你赚到的每一笔，都在这里。

**怎么用**：

- 「近 30 天收入趋势」按日聚合的柱状图（创作者 + 平台各计多少、当天几笔）；
- 创作者卡片显示**累计未提取余额**与分成笔数；点卡片展开**分成流水**（每笔订单金额、创作者分成、平台分成、入账时间）。

**常见问题**：

- *余额怎么提现？* 当前版本为测试通道（Stripe 测试口径）记账，余额为账面口径；接通真实收款后按部署者的提现流程操作。

### 5.3 客户账单

**是什么**：客户为结果付费的明细，随时对账。

**怎么用**：

- 顶部汇总卡：总买家数（已成交）、总订单（支付成功口径）、订单净额（paid + delivered）、RaaS 计费收入、总收入；
- 「按买家查询」：从已成交买家里选，或输入买家 ID——列出该买家的每笔订单与总消费（口径：paid + delivered，待支付 / 退款 / 取消不计入）。

**常见问题**：

- *为什么查不到某笔订单？* 检查它的状态——pending / refunded / cancelled 的订单不计入消费口径。

### 5.4 RaaS 计费——数字员工计费

**是什么**：AI 自己解决问题才收钱，转人工免费。数字员工（RaaS：Result as a Service，按结果服务）每自主解决一单任务计费 ¥2.50。

**怎么用**：

1. 「任务结算」里填任务 ID（如 `task_20260915_001`）、数字员工 ID；
2. 处理结果二选一：**resolved · 自主解决（计费 ¥2.50）** 或 **escalated · 转人工（免费）**；
3. 点**「结算这一单」**，下方汇总区累计 RaaS 总收入与逐单流水。

**常见问题**：

- *为什么转人工不收费？* 这就是 RaaS 的定价承诺：只为结果付费——AI 没解决就不收钱。

### 6.1 账户

**是什么**：你的云操作系统身份。

**怎么用**：

## 7. 团队协作指南

### 7.1 建队与邀请

1. 你和队友都先**各自注册账号**（用户名是邀请的唯一凭据）；
2. 由发起人在**协作团队**面板点「建队」，起个队名（如「出海小分队」）；
3. 队长在队伍卡片里按**用户名**逐个邀请队友；被邀请人刷新后即可看到队伍；
4. 队长可随时把成员移出队伍（成员徽标上的 ×）；只有队长能移人。

### 7.2 团队创意

- 在**总览**记创意时，下拉选择某个团队——这条创意就成了**团队创意**：全体成员都能看、都能接着编辑三域、推进阶段；
- 个人创意依然只有自己可见；市场关注与协同始终记录真实账号（实名互动）；
- 队友可以把创意详情的网址（`#/ideas?id=创意ID`）直接发给你，打开直达详情。

### 7.3 任务板与黑板：分工协作

- **拆活**：把创意推进要做的事拆成任务加进**任务板**，成员各自「认领」；完成要填交付结果，卡住了标「阻塞」写明原因——谁在干什么、卡在哪，一眼可见；
- **共享结论**：需要跨角色留档的发现与结论写**黑板**（workflow 作用域），比聊天记录更不容易丢；
- **AI 也能入伙**：用 **AI 组队**让 AI 角色按目标开工，或在创意详情「MVP 验证」页签启动 **Agent 开发**（可组合架构师 / 开发者 / 审查者三个角色，各自出任务书与产出文件）。

## 8. 订阅与自动续订

订阅制 Skill 按**周期**付费换取使用权益：**包月 / 季付 / 年付**三种周期，到期日即权益窗口截止日。

### 订阅从哪来

- 在 **Skill 市场**对订阅制 Skill 点「订阅」，或在**订单交易**对订阅制 Skill 下单并支付——支付成功即激活，页面显示「权益至 <到期时间>」；
- 安装订阅制 Skill 前系统会校验权益，没有有效订阅会提示先订阅。

### 到期与续订

- **到期懒判定**：到期后权益自动失效，重新订阅即刻恢复；
- **手动续订**：订单交易「我的订阅」里点「续订 / 重新订阅」——按当前市场价下单并支付，权益**从原到期日顺延**（没用完的日期不浪费）；
- **到期提醒**：剩 7 天及以内，订阅行显示黄色「剩 N 天」徽标；
- **自动续订**：每条订阅有「自动续订」开关。**开启后到期由系统每日结算自动按市场价扣款顺延**，不用手动操作；关闭则到期停用，想用再手动续。

### 常见疑问

- *自动续订怎么关？* 「我的订阅」行内取消勾选即可，即时生效。
- *续订从哪天起算？* 从原到期日顺延，不是从付款当天——早续不吃亏。
- *订阅和一次性买断的区别？* 订阅制在权益窗口内可持续使用与更新；一次性买断永久有效。定价模型由 Skill 作者设定（免费 / 一次性 / 订阅三选一）。

## 9. 常见问题 FAQ

**Q：提示「登录已过期，请重新登录」？**
会话 7 天不活跃会过期（期间正常使用会自动续期）。过期后系统自动回到登录页，重新登录即可——**创意、记忆与收入数据都在你的账号里，不会丢**。

**Q：密码连续输错被锁了？**
连续失败过多会短暂锁定（提示「尝试次数过多，请 N 秒后重试」）。等提示的时间过去再试；这层保护是为了防暴力试密码，不是账号出问题。

**Q：启动 Agent 开发没有产出？**
先分清两种情形（系统会显式告警区分）：
- **没跑**：宿主未接入 DSH Agent 服务——此时为记录式降级，角色任务书会落盘到创意工作区（`AGENT-TASK-<角色>.md` 文件），接入 DSH 后可真实拉起；
- **跑了没产出**：通常是**模型未配置**——检查部署环境的 `DEEPSEEK_API_KEY` 与宿主 Agent 服务是否就绪，配置好后重试。
真实模式跑完若自动注册了 Skill 草案，会提示你去 Skill 市场上架。

**Q：搜不到想要的内容？搜索有什么技巧？**
- **顶栏全局搜索**：一处输入，同时跨**创意 / 记忆 / Skill** 三路聚合，点结果直接跳转；
- **记忆体检索**：输入 **3 个字以上**的任意子串（不限整词），如「宠物」能命中「宠物经济」；
- **创意市场**：用问题域 / 解决域 / 时空域里的词当关键词（如「跨境电商」），配合阶段筛选更准；
- **Skill 市场**：支持名称、类别、阶段、兼容版本四个过滤维度，可组合。

**Q：创意归档了怎么恢复？**
归档只是**隐藏不是删除**：创意从你的创意库与市场消失（市场同步下架），数据完整保留。恢复通过同一归档开关反向操作（`archived=false`，可由部署者协助执行）。注意：**恢复后市场不会自动重新上架**，需要在创意详情「市场与协同」页签重新点「发布到市场」。

**Q：界面上金额的单位是什么？**
界面显示一律是**元**（如 ¥9.90）；少数输入框按**分**填写（如下单金额 ¥9.90 填 `990`），输入框旁都有标注，认准「金额（分）」字样。

**Q：没配置 AI Key，哪些功能受影响？**
`DEEPSEEK_API_KEY` 是**可选**的：配置后内容撰写与热点分析走 LLM；未配置时自动降级为模板策略 + 常青选题库。创意、记忆、市场、计费等核心流程全部不受影响。

**Q：Meme Token 积分是币吗？**
不是。它是**社区积分**（界面明示「社区积分 · 非金融产品」），用于记录测试反馈、内容贡献、协同参与等贡献，按角色比例发放。

**Q：我的数据安全吗？**
密码经 scrypt 哈希存储、会话 Cookie 防脚本读取、登录失败锁定防暴力试解；经营数据（订单 / 订阅 / 账单）只认登录者本人。部署侧默认只监听本机回环地址、数据目录仅属主可读写，公网访问须经理由部署者配置的加密反代。服务器侧建议部署者定期用 `deploy/backup.sh` 备份数据目录。
